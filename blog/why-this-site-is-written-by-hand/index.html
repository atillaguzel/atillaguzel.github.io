Why this site is written by hand

18 November 2026

Somebody follows a link to this page. Their browser asks a server for one file and gets it. A stylesheet follows, then a small script and the fonts. After that there is nothing left to fetch.

That somebody is you, a moment ago. Here is the list, as your own browser recorded it.

Sizes are as stored on the server, before compression. A dash means the size was not reported, usually because your browser already had the file. Google Analytics appears only if you accepted it.

This site has no build step. Every page you can visit is a file in a folder, and what is in the file is what you were sent. I chose that on purpose, and I'll show you why.

What it replaced

Go back a few years and follow the same link. The previous version of this site went up in July 2018, and I last touched it in June 2020. Its résumé page was a template. To show you one page of text, your browser would have been handed pieces of a site with 1,451 files in it, and 1,427 of those were Bootstrap, Font Awesome and jQuery. None of that code was mine, and after a few years none of it was current.

Why not a generator

Each page is built for what it says. The post about look-alike names has a sign-up form in it that you can try to fool. The post about slugs shows a title changing stage by stage. Those pieces are written into the page they belong to, and there is no plugin system for them to satisfy.

Nothing goes out of date. There are no packages to update. The one outside thing a page asks for is a typeface, as the list above shows, and it reads fine without it. A page written today should open the same way in ten years.

It reads the same to everyone. The words are in the HTML as it is served, so a search engine, a screen reader and an AI agent get the page you get. There is a sitemap for crawlers and an llms.txt for agents.

What it costs

The header and the footer are copied into every page. Changing the navigation means editing every file. A generator exists to remove exactly that chore.

I can live with it because I do not do the chore alone. I maintain this site with an AI agent, the same way I work on the libraries: it drafts and I read. A file in the repository called DESIGN.md tells it how the site looks, how it sounds and how to add a post. The next change starts from those rules.

The next visitor

Somebody else will follow a link here tomorrow. Their browser will ask for one file, and that file will be the whole page. If you are curious what is in it, view the source. It is all there.

pass it on

If this was worth your time, it may be worth someone else's.
